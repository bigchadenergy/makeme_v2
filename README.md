# Gulfstream Framing Website

A responsive marketing site for Gulfstream Framing, built with Next.js 14 and styled with the Gulfstream Metals brand system.

## Getting Started

```bash
npm install
npm run dev
```

## Features

- Sticky navigation with anchor links to key sections
- Hero banner featuring coastal steel framing imagery
- About, services, benefits, and contact sections tailored to Gulfstream Framing
- Dedicated contact page and password-protected investor overview (`steel`)
- Responsive layout optimized for desktop and mobile experiences
